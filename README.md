# F40 Monitor

一个面向中兴 F40（MU3650）的原生 macOS 菜单栏监控工具，通过设备本地 Web API 读取状态，无需启用 F40 作为 Mac 的默认网络。

## 功能

- 查看本月累计流量、上下行流量和套餐上限
- 查看实时下载、上传速率
- 查看当前连接设备数量
- 显示 4G / 5G RedCap、运营商和信号质量
- 读取最近短信与未读数量
- 快速打开 F40 流量设置页面

## 环境

- macOS 13 或更高版本
- Swift 6 / Xcode Command Line Tools
- F40 管理地址为 `http://192.168.0.1`

## 使用

1. 将 F40 通过 USB 连接到 Mac，并确认可以访问 `192.168.0.1`。
2. 在 macOS“钥匙串访问”中创建一个通用密码项目：
   - 服务：`com.local.f40monitor`
   - 账户：`f40-admin`
   - 密码：F40 Web 管理密码
3. 编译并运行：

```bash
swift build
swift run F40Monitor
```

首次读取钥匙串时，macOS 可能询问访问权限。

## 隐私

管理密码只保存在 macOS 钥匙串中，不会写入源码。程序仅与 F40 的本地管理地址通信。

## 说明

该项目针对 F40 当前固件的本地 Web API 开发。不同地区或固件版本的字段可能存在差异。
